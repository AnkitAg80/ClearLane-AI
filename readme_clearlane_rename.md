# ClearLane AI Rename

## What Changed

The project-facing name was changed to `ClearLane AI` across the app and supporting code text.

## Where It Changed

The FastAPI title now reads `ClearLane AI API` in `app/app.py`.

The dashboard loading screen and left-rail brand now show `ClearLane AI` in `frontend/src/App.jsx`.

The home view heading now welcomes users to `ClearLane AI` in `frontend/src/components/HomeView.jsx`.

The DeckGL layer IDs were renamed to use the `clearlane-*` prefix in `frontend/src/components/CommandMap.jsx`.

Developer-facing descriptions were updated in `scripts/mappls_probe.py` and `src/pipeline.py`.

## Why It Helps

The previous project-facing name overlapped with the hackathon identity, which could confuse judges. `ClearLane AI` makes the product identity clearer and directly communicates the outcome: clearing blocked lanes through intelligent parking-enforcement decisions.

## What Should Happen Next

Use `ClearLane AI` consistently in the pitch deck, demo script, screenshots, and any final submission text.
